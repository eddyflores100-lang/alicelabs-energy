3-Minute Setup

Install in your MCP client

No API key required. Just add to your config and restart.

# ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) # or %APPDATA%\Claude\claude_desktop_config.json (Windows)
{
  "mcpServers": {
    "alicelabs-energy": {
      "command": "npx",
      "args": ["-y", "@alicelabs/energy-mcp"]
    }
  }
}
# .cursor/mcp.json (project-level) or ~/.cursor/mcp.json (global)
{
  "servers": {
    "alicelabs-energy": {
      "command": "npx",
      "args": ["-y", "@alicelabs/energy-mcp"]
    }
  }
}
# ~/.config/cline/cline_mcp_settings.json
{
  "mcpServers": {
    "alicelabs-energy": {
      "command": "npx",
      "args": ["-y", "@alicelabs/energy-mcp"],
      "env": {}
    }
  }
}
# HTTP transport (for hosted agents)
curl -X POST https://alicelabs.energy/mcp/alicelabs-energy \
  -H "Content-Type: application/json" \
  -d '{"tool": "get_market_rates", "args": {"state": "TX", "fuel_type": "Electric"}}'

# Response:
{
  "utility_default_rate": "12.4¢/kWh",
  "auction_clearing_rate": "8.2¢/kWh",
  "savings_pct": 33.9,
  "monthly_savings_estimate": "$420/mo (at 10,000 kWh/mo)"
}

After saving the config file, restart your MCP client. The server will auto-download via npx.
